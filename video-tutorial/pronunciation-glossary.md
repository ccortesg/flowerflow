# Glosario de pronunciación

| Término | Pronunciación sugerida |
|---|---|
| Flower Flow | “fláuer flóu” |
| Florece Hermosillo | “flo-ré-se er-mo-sí-yo” |
| Carlos Cortés | “Cár-los Cor-tés” |
| PDF | “pe-de-efe” |
| Excel | “ek-sél” |
| Autosave | “áu-to-séiv”; en la narración se prefiere “guardado automático” |
| Rúbrica | “rú-bri-ca” |
| Anonimización estructural | “a-no-ni-mi-sa-sión es-truc-tu-ral” |
| ID | “i-de” |
| Wizard | “uí-sard”; en la narración se prefiere “flujo por pasos” |

La voz debe conservar un español de México natural. Los nombres comerciales no se traducen y los acrónimos se pronuncian letra por letra.
